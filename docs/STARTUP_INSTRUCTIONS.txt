WHAT THESE FILES DO:
================================================================================

MAIN STARTUP SCRIPTS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
START.bat
  • Loads configuration from paths_config.ps1
  • Checks if Ollama is running (starts if needed)
  • Checks if ComfyUI is running (starts if needed)
  • Starts FastAPI backend server
  • Waits for all three services to be ready
  • Opens http://localhost:8000 in your browser
  → Use this for NORMAL startup

STOP.bat
  • Stops FastAPI backend
  • Stops ComfyUI and frees GPU memory
  • Stops Ollama
  • Verifies all ports are released
  → Use this for NORMAL shutdown

CONFIGURATION:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
paths_config.ps1
  • Central location for ALL service paths
  • Edit this file ONCE at the beginning with your system paths
  • Includes validation function: Test-ConfigPaths
  → All other scripts load and use this configuration

launch_comfyui.ps1
  • Used internally by START.bat
  • Launches ComfyUI with proper arguments
  • Loads configuration from paths_config.ps1
  → You don't need to run this manually

SERVICES AND WHAT THEY DO:
================================================================================

OLLAMA (Port 11434)
  Role: Generates themed card names, flavor text, and art prompts
  Used for: LLM-based card theming and creative descriptions
  Required: YES
  If it fails: Install from https://ollama.ai
              Then: ollama pull qwen3:14b

COMFYUI (Port 8188)
  Role: Generates custom card artwork using FLUX or SDXL
  Used for: AI image generation, face-swapping, upscaling
  Required: YES
  If it fails: Check paths in paths_config.ps1
              Verify FLUX checkpoint is downloaded
              Check for missing CUDA drivers (NVIDIA GPU only)

FASTAPI SERVER (Port 8000)
  Role: Deck builder backend API + React web frontend
  Used for: Building decks, managing cards, exporting
  Required: YES
  If it fails: Check server.log for error messages
              Ensure Python 3.11+ is installed
              Run: pip install -r requirements.txt

================================================================================
TROUBLESHOOTING:
================================================================================

"Ollama is not running" error?
  → Install Ollama from https://ollama.ai
  → Run: ollama pull qwen3:14b
  → Then run START.bat again

"ComfyUI did not respond" error?
  → Paths in paths_config.ps1 are wrong
  → Run: . .\paths_config.ps1; Test-ConfigPaths
  → Fix any missing paths shown in red
  → Try START.bat again

"FastAPI did not respond" error?
  → Check server.log for error details
  → Is Python installed? python --version
  → Are dependencies installed? pip install -r requirements.txt
  → Is port 8000 in use? netstat -ano | findstr :8000
  → If port is in use: Kill it with taskkill /PID <pid> /F

Port 8000 is already in use?
  → Solution 1: Edit paths_config.ps1 and change $global:ServerPort = 8001
  → Solution 2: Kill the old process: taskkill /PID <process_id> /F

Services won't shut down properly?
  → Use Task Manager to find and kill python.exe processes
  → Or: taskkill /F /IM python.exe /IM ollama.exe

TECHNICAL DETAILS:
================================================================================

Startup Order & Dependencies:
  1. paths_config.ps1 is loaded (no dependencies)
  2. Ollama started/checked (must be running before other services)
  3. ComfyUI started/checked (uses launch_comfyui.ps1)
  4. FastAPI server started (depends on Ollama + ComfyUI being ready)
  5. Browser opened when all services are ready

Service Readiness Checks:
  Ollama:   GET http://127.0.0.1:11434/api/tags         → HTTP 200
  ComfyUI:  GET http://127.0.0.1:8188/system_stats      → HTTP 200
  FastAPI:  GET http://127.0.0.1:8000/api/playstyles    → HTTP 200

Timeout Values:
  Ollama:   15 checks × 2 seconds = 30 seconds max wait
  ComfyUI:  30 checks × 3 seconds = 90 seconds max wait
  FastAPI:  15 checks × 2 seconds = 30 seconds max wait

Port Cleanup:
  START.bat kills any existing process on port 8000 before starting
  This prevents "Address already in use" errors

Logging:
  FastAPI logs written to: server.log
  ComfyUI logs visible in its console window
  Ollama logs visible in its console window
