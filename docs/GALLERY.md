# Gallery — thirteen worlds

Every card on this page came out of the same pipeline: pick a commander, describe a world, and
Myth Forge builds a legal 100-card EDH deck with themed names, flavor text, custom AI art and
print-ready proxy frames. Nothing here was hand-edited.

The [README](../README.md#gallery) carries the highlights; this page is the full set.

All art is generated **locally** (FLUX / SDXL via ComfyUI) and composited into print-ready
frames. Borderless cards were rendered against a locally-installed
[Card Conjurer](INTERNALS.md#optional-official-style-m15-frames-card-conjurer)'s frame assets — **this repo bundles no
Wizards-copyrighted frame artwork**; the built-in frames (e.g. the samurai deck) ship with the app.

## One card, four worlds

The *same* commander (Syr Gwyn, Hero of Ashvale) rethemed into four different decks. The rules stay
identical, but the name, art, flavor — even the creature types in the rules text
("equip **Cowboy**", "equip **Grim Warden**") — follow each world, and the subtitle always shows the
real card:

![The same commander rethemed into four different worlds](samples/one_card_four_worlds.jpg)

## The borderless treatment

official borderless convention, and the proxied card's real name as a subtitle — across every card
type:

## Make your own showcase

```bash
python utilities/generate_samples.py
```

Renders a contact sheet (commander + 3 creatures + 3 spells + 3 lands) from any deck you have
already built, using the deck's own stored renders — no regeneration, no GPU.
