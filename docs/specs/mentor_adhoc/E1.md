# Spec E1 — scripts/bracket_axis_reference.py

Write ONE Python file: a CLI script. Output only code. /no_think

Module docstring: one paragraph saying it sweeps every corpus deck carrying a `# bracket: N`
header, caches per-deck metric rows to JSONL (resumable), and bakes per-bracket p25/p50/p75
into `src/mythgauntlet/ratings/reference.py`; list the CLI usage lines.

## Fixed header (copy exactly, then continue)

```python
from __future__ import annotations

import argparse
import json
import pprint
import re
import sys
import time
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT))
sys.path.insert(0, str(ROOT / "src"))
sys.path.insert(0, str(ROOT / "scripts"))

from bracket_accuracy import labelled_decks  # noqa: E402  -> list[tuple[Path, int]] (path, bracket label)
from mythgauntlet.sim.tier0 import DEFAULT_ANALYZE_TURNS  # noqa: E402

REFERENCE_PY = ROOT / "src" / "mythgauntlet" / "ratings" / "reference.py"
DEFAULT_CACHE = ROOT / ".cache" / "bracket_axis_rows.jsonl"
BEGIN_MARK = "# === BEGIN GENERATED: BRACKET_AXIS_REFERENCE ==="
END_MARK = "# === END GENERATED: BRACKET_AXIS_REFERENCE ==="
THIN_N = 20
EXTRA_METRICS = ("pod", "avg_kill_turn", "avg_commander_turn")
```

Do NOT import advisor / analysis / store modules at module top level (heavy); import them
inside the functions that need them. `METRICS` is computed by `metric_names()`:

`def metric_names() -> list[str]` -> `[*advisor.AXES.keys(), *EXTRA_METRICS]`
(`from mythgauntlet.ratings import advisor` inside the function).

## Functions (exact signatures)

1. `def compute_row(resolved, cfg, store) -> dict[str, float | None]`
   - `from mythgauntlet.ratings.analysis import analyze_deck`; `from mythgauntlet.ratings import advisor`
   - `a = analyze_deck(resolved, cfg, store, run_resilience=True)`
   - Return dict with, for every `axis` in `advisor.AXES`: `axis -> float(advisor.axis_score(a, axis))`;
     `"pod" -> float(a.pod.score)`;
     `"avg_kill_turn" -> a.report.avg_kill_turn` and `"avg_commander_turn" -> a.report.avg_commander_turn`
     (each converted with `float(...)` unless the value is None, in which case keep None).
   - Round every non-None value to 4 decimals.

2. `def load_cache(path: Path) -> dict[tuple[str, int], dict]`
   - Read JSONL (skip blank lines and lines that fail to parse). Each line is an object
     `{"deck": str, "runs": int, "label": int, "metrics": {...}}`. Return mapping keyed by
     `(deck, runs)`. Missing file -> empty dict.

3. `def append_cache(path: Path, row: dict) -> None`
   - `path.parent.mkdir(parents=True, exist_ok=True)`; append `json.dumps(row)` + "\n" (utf-8), flushing.

4. `def percentile(sorted_vals: list[float], q: float) -> float`
   - Linear interpolation between closest ranks (same as numpy default): `pos = q * (len-1)`,
     `lo = floor(pos)`, `hi = min(lo+1, len-1)`, result `v[lo] + (v[hi]-v[lo]) * (pos-lo)`.
     `q` in 0..1. Requires a non-empty list. `import math` inside or at top.

5. `def aggregate(rows: list[dict]) -> dict[int, dict[str, dict]]`
   - `rows` are cache rows (with "label" and "metrics"). Return `{bracket: {metric: cell}}` for
     EVERY bracket 1..5 and EVERY metric in `metric_names()` (even when there are no decks).
   - `cell = {"p25": float|None, "p50": float|None, "p75": float|None, "n": int, "none_count": int, "thin": bool}`
   - `n` = number of non-None values of that metric among rows with that label; `none_count` = number of None
     (or key-missing) values. Percentiles computed over the non-None values, rounded to 2 decimals;
     all three are None when n == 0. `thin = n < THIN_N`.
   - Use `.get(metric)` on the metrics dict.

6. `def render_generated(table: dict[int, dict[str, dict]], *, runs: int, decks: int, date: str) -> str`
   - Return the text that goes BETWEEN the markers, inclusive of both marker lines, ending with "\n":
     ```
     # === BEGIN GENERATED: BRACKET_AXIS_REFERENCE ===
     # Generated by scripts/bracket_axis_reference.py on <date>: runs=<runs>, <decks> labelled decks.
     # Do not edit by hand; re-run the script (and `--check` to detect drift).
     BRACKET_AXIS_REFERENCE: dict[int, dict[str, dict]] = <pprint.pformat(table, sort_dicts=False, width=100)>
     # === END GENERATED: BRACKET_AXIS_REFERENCE ===
     ```

7. `def bake(table, *, runs: int, decks: int, date: str) -> None`
   - Read `REFERENCE_PY` (utf-8). Find `BEGIN_MARK` and `END_MARK`; replace everything from the start of
     the BEGIN line through the end of the END line (including its newline) with `render_generated(...)`.
     Raise `SystemExit("markers not found in reference.py")` if either marker is missing. Write back (utf-8).

8. `def check(table) -> int`
   - `from mythgauntlet.ratings import reference` ; compare `reference.BRACKET_AXIS_REFERENCE == table`.
     For every (bracket, metric) whose baked cell differs from `table`, print
     `DRIFT B<bracket> <metric>: baked <baked cell> now <new cell>`; also print `MISSING` for keys
     absent from the baked constant. Print `BRACKET_AXIS_REFERENCE is current.` and return 0 if equal,
     else print `BRACKET_AXIS_REFERENCE needs regenerating.` and return 1.

9. `def sweep(args) -> list[dict]`
   - Heavy imports inside: `from mythgauntlet.data.scryfall import load_card_db`,
     `from mythgauntlet.model.deck import Deck, resolve`, `from mythgauntlet.semantics.store import SemanticsStore`,
     `from mythgauntlet.sim.tier0 import SimConfig`.
   - `db = load_card_db()`, `store = SemanticsStore()`, `cfg = SimConfig(turns=args.turns, runs=args.runs, seed=42)`.
   - `decks = labelled_decks(args.limit)`; `cache = load_cache(args.cache)`.
   - For each `(path, label)` with 1-based index: if `(path.name, args.runs) in cache` skip (count as cached).
     Otherwise: `resolved = resolve(Deck.parse_text(path.read_text(encoding="utf-8")), db)`;
     if `resolved.card_count < 90` print a skip line and continue; call `compute_row`; inside
     `try/except Exception as exc` print `  [i] <name>: FAILED <exc>` (flush) and continue — never fatal.
     On success build `row = {"deck": path.name, "runs": args.runs, "label": label, "metrics": metrics}`,
     `append_cache(args.cache, row)`, add to `cache`, and every 10 decks print progress
     `  i/total (elapsed s)` with flush.
   - Return `[row for (deck, runs), row in cache.items() if runs == args.runs and deck in {p.name for p, _ in decks}]`
     so only this run's size and deck set are aggregated.

10. `def main() -> int`
    - argparse: `--runs` int default 120; `--turns` int default DEFAULT_ANALYZE_TURNS; `--limit` int
      (default None); `--cache` Path default DEFAULT_CACHE; `--check` flag (recompute from the cache only,
      NO simulation: load_cache, filter to rows whose runs == --runs, aggregate, call `check`, return its code);
      `--bake` flag (after the sweep, write reference.py via `bake`); `--aggregate-only` flag
      (skip the sweep; aggregate from the cache; combine with --bake or just print).
    - Default behaviour (no --bake): sweep, aggregate, print a table: one line per bracket per metric
      `B<b> <metric:<20> n=<n> p25=<..> p50=<..> p75=<..> none=<none_count>` and mark thin cells with `thin`.
    - `date` for bake = `time.strftime("%Y-%m-%d")`; `decks` = number of rows aggregated.
    - Return 0.

Finish with `if __name__ == "__main__": raise SystemExit(main())`.
No other dependencies. Wrap stdout with a utf-8 reconfigure: `sys.stdout.reconfigure(encoding="utf-8", errors="replace")` at the top of main (guard with hasattr).
