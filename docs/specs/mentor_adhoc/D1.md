## Purpose

A pure, deterministic "why is this axis what it is, and what moves it" table for a Magic: The
Gathering Commander deck. It receives a flat dict of already-measured facts about the deck and
returns the axis's drivers (each with a value and a strong/typical/weak reading) and a list of
fixed lever sentences. It runs no simulation and imports nothing from the engine except the
reference table. Do not add any other public function, class or constant than the ones named
below. Do not invent thresholds, drivers or lever text: everything is given below verbatim.

## Reading rule (implement exactly)

`reading(driver, value, bracket)`:

1. `value is None` -> `(driver.none_reading, "none")`.
2. `kind == "bool"`: `("strong" if value else "typical", "fixed_threshold")`.
3. `kind == "empty_list"`: value is a list; empty -> `("strong", "fixed_threshold")`, non-empty ->
   `("weak", "fixed_threshold")`.
4. `kind == "number"`:
   a. If `driver.ref_metric` is set AND `bracket` is not None: call
      `reference.percentile_band(bracket, driver.ref_metric, value * driver.ref_scale)`. If it
      returns a dict (not None), read `band = result["percentile_band"]` and return
      `(r, "bracket_percentile")` where, for `higher_is_better`: `"above_p75"` -> `"strong"`,
      `"below_p25"` -> `"weak"`, the other two bands -> `"typical"`; for `lower_is_better` it is
      mirrored: `"below_p25"` -> `"strong"`, `"above_p75"` -> `"weak"`, the other two -> `"typical"`.
   b. Otherwise (no reference metric, no bracket, or `percentile_band` returned None) use the fixed
      thresholds, basis `"fixed_threshold"`:
      - `higher_is_better`: `value >= strong_at` -> strong; `value < weak_at` -> weak; else typical.
      - `lower_is_better`: `value <= strong_at` -> strong; `value >= weak_at` -> weak; else typical.

## `diagnose` output (implement exactly)

`diagnose(axis, score, why, facts, bracket)` returns

```python
{"axis": axis, "score": score, "why": why,
 "drivers": [{"name": d.name, "value": <facts.get(d.fact)>, "direction": d.direction,
              "reading": r, "basis": basis}, ...],
 "levers": [lever.text, ...]}
```

- `drivers`: one entry per `Driver` in `DRIVER_TABLE[axis]`, in table order, with
  `(r, basis) = reading(d, facts.get(d.fact), bracket)`.
- `levers`: for every `Lever` in `LEVERS` order whose `axes` contains `axis`, whose `driver` names a
  driver of this axis whose reading is `"weak"`, and whose `requires` is None or
  `facts.get(lever.requires)` is truthy: append `lever.text` once (skip duplicate texts).
- An unknown `axis` (not a key of `DRIVER_TABLE`) raises `ValueError(f"unknown axis {axis!r}")`.
