## Purpose

A command-line acceptance bench for the Deck Mentor's open-ended questions. For each chosen
corpus deck it loads the deck exactly like the existing `scripts/mentor_bench.py`, computes
engine ground truth ONCE, asks eight fixed questions through `mentor_chat.ask`, grades each
reply with hand-written mechanical rubrics (imported, NOT written by you), prints a
PASS/FAIL table and optionally dumps everything to JSON.

The grading functions live in a sibling module `scripts/mentor_holistic_rubrics.py` that
someone else writes. You only call them. Do NOT implement any grading logic.

## Module docstring (REQUIRED, keep it short)

State: usage `python scripts/mentor_holistic_bench.py [--decks a,b] [--questions x,y]
[--json out.json] [--model qwen3:14b] [--runs 150] [--turns N]`; that grading is mechanical
(no LLM judge); that rubrics live in `mentor_holistic_rubrics.py`; that exit code is 0 when
the script finishes (it is a measurement, not a gate).

## Functions to implement

1. `load_world(model_unused=None) -> tuple` — load ONCE per process: `db = load_card_db()`,
   `cr = rulings.load_comprehensive_rules()`, `rdb = rulings.load_rulings_db()`,
   `store = load_store()` (print "Loading semantics store..." to stderr before that call).
   Return `(db, cr, rdb, store)`.

2. `build_truth(key: str, path: Path, world: tuple, runs: int, turns: int) -> dict | None` —
   parse `Deck.parse_text(path.read_text(encoding="utf-8"), name=path.stem)`, `resolve(deck, db)`;
   if `resolved.cards` is empty print a stderr message and return None. Then
   `cfg = SimConfig(turns=turns, runs=runs, seed=42)`,
   `ctx = MentorContext(card_db=db, cr=cr, rulings_db=rdb, resolved=resolved, cfg=cfg, store=store)`,
   `analysis = analyze_deck(resolved, cfg, store, run_resilience=True)`,
   `stats = tool_get_deck_stats(ctx).data`; identity and deck_names as above. Return the truth dict.

3. `run_deck(key, truth, questions, model) -> list[dict]` — for each selected question IN THE
   ORDER OF `QUESTIONS` (filtering by the requested ids): build `history` — if the question's
   `follow_up_of` is set and that question has already been asked THIS run, history is
   `[{"role": "user", "content": <that question text>}, {"role": "assistant", "content": <that reply text>}]`,
   else `None` (a follow-up whose parent was filtered out is asked with no history). Call
   `mentor_chat.ask(truth["ctx"], text, history, model=model)`, time it with `time.time()`,
   then `passed, reason = rubrics.grade(qid, reply, truth)`. Append a row dict:
   `{"deck": key, "qid": qid, "question": text, "passed": passed, "reason": reason,
   "gated": reply.gated, "seconds": round(dt, 1), "reply": reply.text,
   "tools": [t.name for t in reply.tool_trace],
   "tool_trace": [{"name": t.name, "args": t.args, "result": t.result_data} for t in reply.tool_trace],
   "rejections": [{"draft": d, "reasons": r} for d, r in reply.gate_rejections]}`.
   Keep the `MentorReply` objects in a parallel list so you can call
   `rubrics.grade_colour(replies, truth)` afterwards; append one more row with `qid = "colour"`,
   `question = "(all replies)"`, `reply = ""`, `gated = True`, `seconds = 0.0`, empty tools/
   tool_trace/rejections. Print one progress line per row to stderr as they finish
   (`[key] qid PASS|FAIL|n/a  (12.3s)`).
   Wrap `mentor_chat.ask` in `try/except mentor_chat.LLMUnavailable` -> print the error and exit
   code 2 via `sys.exit(2)`.

4. `fmt(passed)` returns `"PASS"`, `"FAIL"` or `"n/a"` for True / False / None.

5. `print_table(rows, deck_keys, qids)` — a plain-text table to stdout: one row per deck, one
   column per qid (plus `colour`), cells `PASS`/`FAIL`/`n/a`/`--` (`--` when that cell wasn't run).
   Below it, for every FAIL row print `  [deck] qid: <reason>` (reason only, one line each).
   Then a per-question summary line: `qid: P/T (xx%)` where T excludes n/a and P counts passed
   (skip questions with T == 0 and print `qid: n/a`). Finally an overall line
   `OVERALL: P/T (xx%)` over every non-n/a cell. Also print the gated count:
   `gated on first attempt: G/N` where a row counts when `gated` is True and `rejections` is empty
   (exclude the colour rows).

6. `main() -> int` — argparse with `--decks` (comma list; match against the DECKS key OR the
   filename; unknown value -> `p.error`), `--questions` (comma list of qids; unknown -> `p.error`),
   `--json PATH`, `--model` default `"qwen3:14b"`, `--runs` int default 150, `--turns` int default
   `DEFAULT_ANALYZE_TURNS`, `--list` (print the DECKS table and exit 0). Load the world once; loop
   decks (skip a deck whose `build_truth` returns None), collect all rows, print the table. If
   `--json` given write `{"model":..., "runs":..., "turns":..., "rows": rows, "started": <iso
   timestamp string>}` with `json.dump(..., indent=2, ensure_ascii=False, default=str)`. Return 0.
